# REHANVERSE 🚀

REHANVERSE is a modern full-stack EdTech platform built to make online learning simple, secure, and organized.

The platform allows students to explore courses, access video lectures, read PDF notes, attend live classes, upload payment proof for paid courses, and manage their enrolled courses from a clean dashboard.

Admins can create and manage courses, upload learning materials, approve payment requests, monitor users, and control course access through a dedicated admin panel.

## ✨ Key Features

- Student authentication and secure login
- Course listing with videos, PDFs, and live classes
- Free and paid course support
- Manual payment proof upload and admin approval
- My Courses dashboard for enrolled students
- Admin panel for course, user, and payment management
- Protected PDF viewing experience
- Responsive and modern UI
- Dark/light theme support
- Security activity logs

## 🛠 Tech Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
- Storage/Uploads: Multer / Supabase
- Deployment: Vercel + Render
